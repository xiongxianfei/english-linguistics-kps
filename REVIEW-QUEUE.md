# Scientific review queue

## Key takeaway
Review evidence and scope rather than promoting claims because files or tests exist.

## Summary
This is an optional catalog of canonical Markdown, not another knowledge store. Each item has a local summary here; its full explanation, examples and limits remain in its owning file. All linguistic content is provisional.

## Review operation

For an item below, identify a bounded claim, inspect the relevant source passage, compare its scope with the local explanation, check a counterexample and record what remains unsupported. A citation is not blanket support, and a constructed example is not a study. Do not change scientific review status without an actual version-specific review record.
