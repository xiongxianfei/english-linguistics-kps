# AI contribution guidance

## Key takeaway
Automated assistants must preserve authoring, evidence and permission boundaries.

## Summary
Automated assistants must preserve authoring, evidence and permission boundaries. The initial broad release remains provisional; supporting links and checks do not constitute independent scientific review.

## Authority

AUTHORING.md applies the pinned upstream KPS authoring contract to this package. SCOPE.md and CHECKS.md state this domain's scope and verification limits. Do not redefine KPS roles, make up review records, or silently turn a provisional analysis into established science.

## Work method

Read the relevant source files and dependencies first. Use the smallest coherent change. Distinguish source statements, authored inference, pedagogical simplification and observations. Keep constructed examples labelled. Do not infer source inspection from a citation title or generate answer-shaped evidence.

## Execution

Run actual checks and report failures honestly. Preserve branch protection and do not force-push shared branches. Do not run --accept-reviewed-summaries just to make a check green. That flag records an actual summary review; it does not perform one.

## Data and content

Never bundle private user conversations or third-party copyrighted material under the MIT notice. Do not claim a generated diagram, IPA string or unit test establishes linguistic truth. Missing context or recordings must stay missing in the published analysis.
