# Scientific review queue

## Key takeaway
Every initial linguistic object remains provisional and needs independent claim level review.

## Summary
Generated navigation over canonical knowledge objects. Stage labels record coverage, not empirical mastery or KPS knowledge roles. All linguistic content in this initial release is provisional.

## Review priorities

Prioritize theory-sensitive analyses, accent-sensitive phonetics, generalized negation and scope claims, and source gaps. Bibliographic existence, selected-source inspection and full claim verification are different statuses. A source-backed definition can coexist with unverified examples and explanations in the same note.
