# Expression and representation

## Key takeaway
A linguistic expression and an analysis of it are different objects.

## Summary
A linguistic expression and an analysis of it are different objects. The definitions and worked cases below state the intended analysis and its limits. This initial object is provisional; links deepen the explanation but do not replace it.

## Definition

A linguistic expression and an analysis of it are different objects. The written string, a recording of an utterance, a bracketed syntactic structure, and a semantic formula can represent related information without being interchangeable. This package records the exact expression before assigning analytical labels.

## Worked example

For the constructed sentence "Maya opened the window", the expression "the window" is a written string. In our working syntax it forms an NP and functions as Object. In the described opening event its referent is a Patient. The label NP is neither the window itself nor its semantic role.

## Distinctions

An expression is not its category. A representation is not direct access to a speaker's mental grammar. A useful diagram also need not be a model of the chronological stages of comprehension.

## Scope and limits

The starting distinctions are descriptive conventions. Speech, writing and signed languages have different physical realizations; this package concentrates on spoken and written English. The sample analyses are proposed instructional analyses, not observations from a recorded experiment.
