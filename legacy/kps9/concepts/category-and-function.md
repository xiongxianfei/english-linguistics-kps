# Category and function

## Definition

A syntactic category classifies an expression by its structural and distributional properties; a grammatical function describes its relationship within a larger construction. The same category can occur in different functions. Category and function labels must therefore be recorded in separate fields.

## Worked example

"The old computer failed" and "Anna repaired the old computer" contain the same NP string. It is Subject in the first sentence and Object in the second. "Anna became a technician" also contains a postverbal NP, but it describes Anna rather than naming a separate participant she acted on.

## Distinctions

NP does not mean Subject; PP does not mean Modifier; postverbal position does not guarantee Object. Start with the complete constituent, then state the construction and the local relationship.

## Scope and limits

This package adopts NP terminology for nominal expressions. DP analyses are a substantive theoretical alternative, not a spelling variant. Clause functions and dependency conventions also vary across frameworks.
