# Wh dependency

## Key takeaway
A wh-dependency links an interrogative or relative expression with a grammatical position in a clause.

## Definition

A wh-dependency links an interrogative or relative expression with a grammatical position in a clause. The wh-expression itself, the position's function and the resulting construction are different analytical objects.

## Worked example

"What did Nina read __?" has an Object dependency. "Who did Nina speak to __?" links who with the complement of TO, not a Direct Object of SPEAK. In "What do you think Nina read __?", the gap is inside the embedded clause.

## Distinctions

Subject "Who arrived?" has no object-like missing position after the verb. Relative "the report that Nina read __" shares an Object dependency but is not thereby a main interrogative.

## Scope and limits

Unbounded does not mean unconstrained: islands and extraction restrictions require further investigation. Gap notation is intentionally compatible with more than one formal theory.
