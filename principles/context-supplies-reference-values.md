## Statement

Conventional meaning can constrain reference without uniquely determining the referent of an utterance.

## Explanation

A speaker-relative pronoun gives an interpretation rule whose value varies across utterances. Reference resolution therefore needs contextual parameters or discourse information in addition to an abstract string. This is compatible with theories that include context parameters within formal semantics.

## Worked contrast

When Maya says I, Maya is normally the referent; when Ravi says I, Ravi is. The lexical instruction is similar, but the resulting value changes. A sentence containing here cannot always identify a particular location without its use context.

## Scope and counterevidence

This is not a claim that reference is arbitrary or wholly pragmatic. Quotation, demonstratives and binding require separate analyses, and some pronouns receive bound-variable rather than simple coreferential interpretations.
