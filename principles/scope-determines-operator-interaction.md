## Statement

Reversing quantifier or negation scope can change truth conditions while leaving overt words in the same order.

## Explanation

The outer operator specifies the domain within which an inner interpretation is evaluated. Universal-over-existential permits a different witness for each individual. Existential-over-universal requires a shared witness. In a fixed classical model these are distinguishable logical conditions.

## Worked contrast

With three teachers recommending separate books, EVERY > A can be true while A > EVERY is false. If all recommend one common book, both can be true. Thus the readings are not "different books" versus "same book" as mutually exclusive situations.

## Scope and counterevidence

The logical result is conditional on the declared model; it does not prove both readings are equally available for every English sentence. Empty restrictors and contextual domain restrictions must remain visible.
