# Reference and denotation

## Key takeaway

## Definition

Reference concerns what an expression is used to pick out in context; denotation is a semantic value under an interpretation. Conventional meaning constrains but does not always uniquely identify a contextual referent. A name, a description and a quantifier need not have the same semantic type.

## Worked example

In one context Maya and the researcher can identify the same individual without being synonymous. My supervisor follows a speaker-relative interpretation pattern and can identify different people when different speakers use it. Every researcher does not behave like a simple name for one person.

## Distinctions

An event can count as an entity in a broad semantic ontology. Thus "the explosion" is event-denoting, not evidence that events cannot be entities. The stronger warning is that NP category alone does not fix one semantic type.

## Scope and limits

Theories differ over descriptions, names and generalized quantifiers. Fictional and hypothetical discourse can introduce interpretable referents without establishing actual-world existence.
