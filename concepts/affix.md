# Affix

## Summary
An affix is a bound morphological element attached to a base in the analysis adopted here. The definitions and worked cases below state the intended analysis and its limits. This initial object is provisional; links deepen the explanation but do not replace it.

## Definition

An affix is a bound morphological element attached to a base in the analysis adopted here. Prefix and suffix identify position; inflection and derivation identify the kind of morphological relationship. Position alone does not settle whether a new lexeme is formed.

## Worked example

In unhelpful, un- is a prefix and -ful a suffix; both participate in derivation. In teachers, -er derives TEACHER and -s realizes plural inflection. In schoolteacher, school is a lexical compound member, not a prefix merely because it is written first.

## Distinctions

An element such as -s is not the same kind of answer as the operation inflection. The comparative -er in taller and agentive -er in teacher have different roles despite similar spelling.

## Scope and limits

Affixes, clitics, combining forms and compound members have nontrivial boundaries. This note is an introductory convention, not a complete diagnostic for every bound-looking form.
