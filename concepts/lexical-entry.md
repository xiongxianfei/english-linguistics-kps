## Definition

A lexical entry represents item-specific linguistic information relevant to a lexeme or sense: form, category, paradigm, meaning, selection, alternations and conventional combinations. This is a model of linguistic knowledge, not a claim that every item is stored in one mental database row.

## Worked example

For placement PUT, an entry links an Agent/Causer, Theme and location/Goal to Subject, Object and locative complement patterns. For DEPEND, the dependence sense licenses an on-PP. A translation equivalent alone does not provide these distinctions.

## Distinctions

A sense-specific entry is not merely a spelling with one gloss. RUN in locomotion and management uses exhibits different participant structures even when the word form runs is unchanged.

## Scope and limits

Lexicalist and constructional approaches distribute information differently. This package explicitly uses a descriptive entry as a documentation device and leaves psycholinguistic storage claims unverified.
