# Valency and argument structure

## Key takeaway
Valency describes a head's capacity for core arguments; argument structure represents the associated participant relations.

## Summary
Valency describes a head's capacity for core arguments; argument structure represents the associated participant relations. The definitions and worked cases below state the intended analysis and its limits. This initial object is provisional; links deepen the explanation but do not replace it.

## Definition

Valency describes a head's capacity for core arguments; argument structure represents the associated participant relations. Semantic valency, syntactic valency and overt complement count are not automatically identical. State explicitly whether the subject is included.

## Worked example

In the working semantic count, SLEEP has a Sleeper, transitive READ has a Reader and content, and placement PUT has Agent, Theme and location. "Nina read quietly" can leave content unexpressed; quietly does not become an argument simply by occupying a position after the verb.

## Distinctions

An implicit participant is not an overt NP. Optional expression is not sufficient evidence for modifier status. A trivalent predicate need not have three Objects.

## Scope and limits

Counts depend on lexical sense and construction. Semantic roles are descriptive labels with disputed inventories. These entries are introductory analyses, not a universal theta-role theory.
