# Root base and stem

## Key takeaway
A root is a minimally analyzable lexical core within the chosen morphological analysis.

## Summary
A root is a minimally analyzable lexical core within the chosen morphological analysis. The definitions and worked cases below state the intended analysis and its limits. This initial object is provisional; links deepen the explanation but do not replace it.

## Definition

A root is a minimally analyzable lexical core within the chosen morphological analysis. A base is the expression to which a particular operation applies. A stem is the base relevant to inflection. These labels describe different relationships and can coincide in simple words.

## Worked example

For restarted, START is the root; start is the base for derivational re-; restart is the stem receiving past -ed. For schoolteachers, school and teach are lexical roots in the compound structure, while schoolteacher is the stem for plural inflection.

## Distinctions

The base must be stated relative to an operation. Restart cannot be the input base for adding re- if that operation is precisely what creates restart.

## Scope and limits

Stem and root conventions vary by framework. The examples use transparent English formations; lexicalized words can resist synchronic segmentation even when historical components are recognizable.
