# Compositional and event representations

## Key takeaway
Semantic representations need explicit combination rules and a declared account of participants and situations.

## Summary
Selected passages support typed contributions, function application, event-based modification and distinctions in aspect.

## Publication and inspection

[Author-hosted draft](https://eecoppock.info/bootcamp/semantics-boot-camp.pdf), accessed 2026-10-14. The date identifies the inspected version of this changing URL. Inspection used selected extracted text; source diagrams were not visually inspected or copied.

## Contribution

Sections 5.1–5.2 and 6.2–6.3 connect individual and property contributions through function application. Sections 10.1–10.2 motivate event variables and separate participant relations; 10.6 introduces situation classes. Section 11.1.1.3 distinguishes viewpoint aspect and the perfect. The Models' report examples, grouping sketches and simplified event record are authored adaptations.

## Nonclaims

No full-book inspection, exercise completion, empirical replication or independent linguistic review is claimed. The local Models do not adopt the book's complete type system, grammar, event-composition rules or aspect theory. Other frameworks and unresolved interface questions remain relevant.
